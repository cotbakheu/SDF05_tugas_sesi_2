# Tugas Sesi 2 - Prinsip Clean Code dan Penamaan Fungsi

## Refleksi

- Penamaan variabel dan fungsi dibuat se-deskriptif mungkin agar tujuan penggunaannya mudah dipahami dan mengurangi risiko kekeliruan saat proses pengembangan.
- Nama fungsi dipilih berdasarkan tugas utamanya, yaitu menghitung harga dengan mempertimbangkan jumlah satuan, status membership, dan biaya ongkir.
- Perilaku program dijaga agar tetap konsisten dengan melakukan pengujian secara berkala selama proses penulisan ulang kode, sehingga output yang dihasilkan tetap sesuai dengan ekspektasi.
